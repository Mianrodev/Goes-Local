# v16.15-shared (30 Sep 2026)

## Blog and news posts
- **Double-escaped "&":** 22 of Miami's 25 posts showed "&amp;" in their text (e.g. "Park &amp;amp; Shop"), and links containing "&" were broken.
  - **Cause:** `sanitizeRichHTML` escaped entities the editor had already escaped. `FIXAMP` now collapses them when a post is saved.
  - **Posts already saved:** `renderPostBody` applies the same fix when a post is shown, so they are repaired without changing the database.
  - "&lt;" and "&gt;" are never collapsed, so escaped text cannot become tags.
- **Anchor-only headings:** a heading that was only an anchor name (e.g. "cheapest-parking-options") is shown as readable text ("Cheapest parking options").

## Advertise link
- `/advertise` sent logged-out visitors (e.g. from a banner's "Advertise here") to the login page. They now go to `/pricing`.
- Logged-in owners still go straight to picking an ad spot.
