# v16.25-shared (6 Oct 2026)

Branded emails (Eric approved the mockups). Every email the site sends now uses one frame:
- **Header:** the city's own logo (content_images `brand_logo`), or the brand name in text if none is set, above a coral rule.
- **Body:** a white card on cream.
- **Footer:** brand, city, links to the site/About/Privacy.
- **Build:** table layout and inline styles, so it holds up in Gmail and Outlook. A hidden preheader line sets the inbox preview text.
- `MAILSHELL`, `MAILH`, `MAILBADGE`, `MAILBTN`; `MAIL` gains a `badge` argument; new `MAILCODE` for code emails; `MAIL_INTERNAL` uses the same frame with a "Team notification" badge.
- **Claim invite:** new subject "{business} is verified — manage your free listing", a "✓ Verified on {brand}" badge, a 3-point checklist, and a box showing which email to sign in with.
- **New enquiry to owner:** subject "New message from {name} via {brand}". The customer's message is shown in a quote box with their name, email and phone, and the "Reply to {name} →" button opens a pre-addressed reply (mailto:).
- **Sign-in / sign-up codes:** large navy code block.
- Templates can now carry `badge`, and `btn` supports {{vars}}. Staff edits in /admin/emails still override subject/title/body/button.
