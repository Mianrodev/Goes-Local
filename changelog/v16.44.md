# v16.44-shared — GHL tags clean themselves up

Includes v16.43 (state sites: short site name on phones).

Eric asked on 13 Oct for a QA of the tags the website adds and removes. Dr. Efraín's CFL Counseling had both "claimed" and "claim-request". Some claimed listings still had "pending-listing".

## What changed

The hourly GHL sync now tidies up to 25 contacts per page:

- **"pending-listing" is removed from a claimed live listing.**
  - Unclaimed contacts keep it: they really do have a submission waiting in Admin → Pending listings.
- **"claim-request" is removed from a claimed business** once no claim for it is still pending in the claims queue.
  - This also covers listings marked "claimed" by hand in GHL, and cases where the website's remove call failed quietly.
- **"claim-request" is removed from a claimant's own person contact** (tagged owner-account/consumer) once none of their claims is still pending.
  - Approving a claim only cleans the business contact, so the person's tag used to stay forever.
