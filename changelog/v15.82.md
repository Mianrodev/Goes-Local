# v15.82-shared (25 Sep 2026)

Categories clean-up (Eric: "there are too many main categories").

**Problem:** the ~30 main categories are a fixed list (`MAINS`), and business types are filed under them by a lookup table (`SUBMAP`) and keyword rules (`KW`). When a type matched neither, `mainOf()` returned the type itself (`TC(sub)`), creating a new main category. Miami had 132 main categories — 107 of them stray types such as "Toyota Dealer", "Window Tinting Service", "Gas Station" (634 listings). The /categories page also showed every main category in random order.

**Changes:**
- `mainOf()`: after `SUBMAP` and `KW` (unchanged, so already-filed types don't move), also tries each part of a combined type ("A, B, C") against `SUBMAP`, then new rules `KW2` (dealers → Auto Sales & Rental, window tint/gas station → Automotive, supplier/manufacturer → Professional & B2B, etc.), and finally falls back to **"Other"** — never a new main category. Simulated on Miami's 107 stray types: all land in a sensible main category.
- **Admin → Content → Categories** (new, admin + agent): lists main categories with counts and business types (search, filter by main), and lets staff move any business type to a different main category or type a new main category name. Stored per city in D1 `category_map(sub_slug, sub, main)` — this overrides everything, including a main category typed into the GHL "category" field. Reserved page names (blog, admin, …) are refused. Applied on the next sync pass; the sync already gives moved listings new URLs and records the old ones in `slug_redirects`.
- `/categories` page: only real main categories, biggest first ("Other" last), each card with photo, listing count, its top 4 business types and "+ N more". Header: "N main categories · N categories · N listings" — the homepage "All N categories" number is unchanged, as Eric asked.
- Old category URLs that no longer exist (e.g. `/window-tinting-service`) 301 to the business type's new home (`/automotive-repair-and-services/window-tinting-service`), keeping the query string.

Needs `/admin/migrate` (creates `category_map`) — done by deploy.sh.

Tested locally with `wrangler dev` + seeded D1: /categories render, redirects (301/404), admin set / new main / reserved name / undo / login required; `norm()` tested with fake GHL contacts.
