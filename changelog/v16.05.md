# v16.05-shared (29 Sep 2026)

Only `seoinbound` now (Eric). Email is already tracked in GHL by the `emailreplied` tag.

- **`emailinbound` removed:** v16.04 added it, but the site no longer adds it. Email clicks, including visits from webmail sites like Gmail (whose address contains "google"), get no tag.
- **`seoinbound` stays on a lead forever:** nothing removes it when a lead is approved, claimed or published.
  - **Publishing a pending listing:** the tag is added to the contact that gets published. This covers the case where the original contact couldn't be created at submission, for example because of a duplicate email.
  - **Claims:** the tag goes on both the person claiming and the business contact. The listing stays marked as an SEO lead after it's claimed.
- **New admin tool `/admin/seotags`:** it adds `seoinbound` to every past lead whose recorded source was a search engine or AI assistant. It only adds tags, so it's safe to run again.
  - First run: 4 Orlando leads and 13 Miami leads, mostly from ChatGPT.
