# v16.33-shared — fewer pages for Google to report

Search Console was emailing about "Blocked by robots.txt", "Alternate page with proper canonical tag" and similar. Google found those pages through our own links.

- **Filter, sort and claim links are hidden from Google.**
  - Affected links: any `<a>` on a public page whose address has `hood=`, `rating=`, `claim=`, `sort=` or `sub=`, or that points to `/claim/start?id=…`.
  - The link now carries the plain page (`/category/sub`, or `/claim`), with the real address kept in `data-go`.
  - A small script swaps the real address in when a person clicks, taps or tabs to the link, so visitors see no change.
  - Google renders pages but doesn't click links, so it stops finding about 30k claim addresses and the filter combinations.
  - Done centrally in `R()` (public pages only) via `HIDELINKS`.
- **`/neighbourhoods/<anything>` now 301s to `/neighbourhoods`.** Before, any address like this showed the list page at a second address (a soft duplicate).

Pages Search Console has already reported will fade out over the next few weeks as Google re-crawls. Until then the reasons stay listed.

Status: committed, not yet deployed (waiting on Eric's go-ahead).
