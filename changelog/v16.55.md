# v16.55-shared — auto-approve switch (Home Services state sites)

Eric, 15 Oct: "Approve all listing requests for now and for future."

- New Variable `CITY_AUTO_APPROVE=1` (`AUTO_APPROVE(env)`). Set on ny, il, ga, nc, ma, pa only. City sites do not set it, so nothing changes there.
- **Claims:** `/api/claim` approves straight away (`approveClaim`: owner email, "claimed" tags, claim-approved email with a sign-in link, welcome-call task). The page says "It's yours". A listing someone else already owns still uses the code + 72-hour notice route.
- **New listings:** `/api/lead` type=add publishes straight away (`publishListing`) and says "You're live". If publishing fails it falls back to the normal code route.
- **Hourly catch-up (`autoHourly` step 0):** any claim or new listing still waiting is approved or published (20 per run), skipping listings owned by someone else.
- Nobody is logged in automatically; the sign-in link goes by email, as with code approvals.
- Turn it off later by deleting the Variable (or setting it to 0); the code flow then applies again.

## Payment links (temporary)

The state sites use Miami's four payment links (CITY_PAY_PLUS_MONTH/YEAR, CITY_PAY_PRO_MONTH/YEAR, link.fastpaydirect.com). The buttons show only when PAYMENT_WEBHOOK_KEY is set on the site; payments land in the Miami GHL account, so upgrades on state sites are switched on by hand for now.

## QA

- The 74-test verification suite passes unchanged.
- Local check with the switch on: an unowned claim is approved instantly with the note "[approved automatically (CITY_AUTO_APPROVE)]"; a claim on an owned listing goes to the code page; an add that cannot publish (no GHL locally) falls back to the code page.
