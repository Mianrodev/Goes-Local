# v16.71-shared — owner area: password hint, new Your Profile, one Manage listing page

Eric (23 Oct, after a demo-account walkthrough on a state site): people who haven't set a password should get a
subtle hint on how and why; design updates in Your Profile; Edit listing and Manage listing as one page.
Mockup approved ("Yes please go ahead").

## Your Profile (/account)
- Soft green hint at the top, only when no password is set: "Set a password to sign in faster next time" with why,
  [Set a password] and "Not now" (hidden 30 days on that device, localStorage). Password state comes from the GHL
  "Owner Credentials" field via `hasPassword()`, remembered in KV (`haspw:<email>`; "not set" re-checked every 10 min);
  set on password save, reset and password sign-in (`markPw`). If GHL can't be read, no hint is shown.
- Businesses as compact rows: photo, Verified/plan badges, progress bar with the next missing item (links straight to
  that section), reviews waiting / page views this week / followers (from reviews, events, follows), one
  **Manage listing** button + View page.
- Account box: Your details · Password (Not set / Change) · Sign out. Following and Your reviews underneath.

## One Manage listing page (/manage/hub)
- Tabs: **Your listing** (new, first) · Reviews · Photos · Updates & offers.
- Your listing = the old edit form, in sections (Basics, Contact, Opening hours, Services, Photos & logo) with a
  side list showing ✓/＋ per section and the progress card. Sticky navy save bar ("You have unsaved changes"),
  leave-page warning when unsaved. "Same hours Monday to Friday" (ticked automatically when Tue–Fri match Monday;
  copies Monday's times on save).
- /manage/edit (old links, emails, every save/photo redirect) now forwards to /manage/hub, keeping the message
  (err/ok/warn/note → lerr/lok/lwarn/lnote) and any #sec-… anchor; photo uploads come back to #sec-photos.
  #request still opens Reviews. "Edit listing" button removed; crumb is Your profile / business name.
- Phone: section list becomes chips; photo rows no longer overflow the screen.
- Password page: crumb Your profile / Password, wording explains the benefit.

Also includes v16.68–v16.70 from the states session (qa-contact helper; loadHoods in insertOne/refreshOne).
