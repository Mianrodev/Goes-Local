# v16.23-shared (5 Oct 2026)

Fixes from the CoSuite (Miami) support call: the owner couldn't find how to manage her listing, and the review count didn't match Google. v16.22 was a test copy only.

- **Review counts match Google:** once Google Places has refreshed a listing (claimed listings only), the site now shows Google's own rating and review count instead of the older CRM import, in ROWOF, so it applies everywhere. CoSuite: 117 → 139.
- **"Sign in to manage this listing →"** link on claimed business pages. Before this, a claimed page had no way in for the owner.
- **Claim-invite email:**
  - The button is now "Manage my listing".
  - It goes to /login?tab=signup&email=<owner email>, with the email pre-filled. It used to go to the public page, which (once claimed) had no claim or manage button.
  - The text says which email to use, and to log in if a password is already set.
  - New template variable {{email}}. No city had customised this template, so the new default applies.
- **/login** accepts ?email= to pre-fill both the Log in and Sign up email boxes.
