# v15.96-shared (28 Sep 2026)

Picture rule, as Eric asked.

- **Unclaimed listings always show the default "unclaimed" picture** (the shop with a question mark, `DEFAULT_LISTING_IMG`), in listing cards and on the listing page. They no longer use a picture scraped from their website or a category photo, which made similar businesses look identical.
- **Claimed listings show their own picture:** the profile slot first, then the logo. A claimed listing with no picture keeps the category photo, as before, so it doesn't get the "unclaimed" picture next to its Verified badge.
- `bizImg` returns `DEFAULT_LISTING_IMG` for any unclaimed listing. `PHOTO` and `AVATARIMG` follow the rules above, and broken images fall back the same way. Structured data still leaves out the image when it is the default picture.
