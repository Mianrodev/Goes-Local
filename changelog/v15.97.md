# v15.97-shared (28 Sep 2026)

Changes the SEO team asked for (points 1, 2 and 4 of their list), approved by Eric.

## 1. Image alt text and an image gallery
- **Blog/news image uploads were broken.** The editor sent the picture as `file` but the server only read `image`, so every in-post upload failed with "No image provided". The server now accepts both.
- **Every image uploaded through the site is remembered** in a new `media` table (`recordMedia`, called from `ghlUploadMedia`), with alt text made from the file name (`ALTOF`). For example, "best-nail-salons_brickell.jpg" becomes "Best nail salons brickell". Camera-style names like IMG_1234 or "Screenshot …" give no alt text. Existing blog cover images are added on migrate, using the post title as alt text.
- **Image gallery panel to the left of the blog and news editors** (`MEDIAPANEL`):
  - Click a picture to insert it at the cursor, with its alt text.
  - The alt text can be edited under each picture, and the change is saved for next time (`/admin/media/alt`).
  - New uploads appear in the gallery straight away.
  - The list comes from `/admin/media/list`, admin and agent only.
- **Alt text is kept when a post is saved.** `sanitizeRichHTML` used to replace every alt text with an empty one. It now keeps the alt text, or takes it from the media table.
- **Pictures in posts with no alt text get the post's title** at display time (`ALTFILL`, blog and news).
- Pictures on public pages that had empty alt text now have one: news images, extra photos on listing pages, and hero slides.

## 2. Blog posts on category pages
- Main category pages, and their business-type pages, show a sliding row of blog posts from that category ("From our blog: {Category} guides and tips") under the FAQ.
- Posts are matched on the post's blog category, newest first, up to 12. The row is hidden when a category has no posts.

## 4. SEO text for any page
- **Admin → SEO has a new "Any other page" section.** Paste any page link, such as a neighbourhood, category, business type, Best-of list, listing or blog post, then set its Google title and description and optional extra JSON-LD structured data. Pages that have their own text are listed below the form with Edit and Reset buttons.
- Stored in `site_seo` with the key `path:/the/page`. `PAGESEO` applies it inside `PAGE` by matching the page's canonical path, and any extra structured data is added to the page's automatic data.
- **Better automatic text for neighbourhood pages:**
  - title: "{Hood}, {City}: N local businesses | {Brand}"
  - description: "{description} in {Hood}. Browse N local businesses … ratings, phone numbers, hours and directions."
  - This replaces the old description, which started with ". Browse" for neighbourhoods with no description.

## Data (not code)
- Neighbourhood descriptions were added in Admin → Neighbourhoods for every neighbourhood that had none: 21 in Miami and 33 in Orlando. Each is based on the most common businesses listed there.
