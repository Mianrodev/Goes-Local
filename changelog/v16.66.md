# v16.66-shared — email templates save again; {{city}} / {{website}} placeholders; new line in the claim invite

Eric (22 Oct): saving the "Invite a verified business to claim its listing" email failed with
`D1_ERROR: table email_templates has no column named title`.

## Why it failed
The email editor saves subject, heading (`title`), body and button text (`btn`), but `migrate()` only ever created
`email_templates(key, subject, body, updated_at)`. So every save of a changed email failed on every site, and no
custom wording was ever used.

## Fix
- `migrate()` adds `title` and `btn` to `email_templates` (idempotent).
- New placeholders on every email, filled from each site's own settings (no city text in the code):
  `{{city}}` (Miami / Orlando / Tampa / Georgia / New York …), `{{brand}}`, `{{website}}`. Listed in the editor,
  and the preview shows this site's real values.
- `claim_invite` default body now opens with: "Your business was recently added to {{brand}}, the largest local
  directory in {{city}}, so local customers in {{city}} can find you, which means more business for you."

## Tests
- Local, on a table without the new columns: migrate → save a changed email → "Saved", "Customized", preview
  uses the saved wording with {{city}} filled; reset works. 77/77 suite.
