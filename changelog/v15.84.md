# v15.84-shared (25 Sep 2026)

Edge caching (cost plan Phase D). Before this, every request — ~90% bots — rebuilt the page from D1; Cloudflare doesn't cache a Worker's own responses unless the code uses the Cache API.

- Public GET pages the code already marks `public` (via `R()`), plus sitemaps, robots.txt and llms.txt, are stored in `caches.default`.
- Lifetimes: homepage 10 min, blog/news 15 min, sitemaps/robots 12 h, everything else (categories, business pages, neighbourhoods…) 1 h.
- Cache key = path + only the query parameters the site actually reads (tracking and junk parameters are ignored, so `?utm_…` or `?r=123` can't force a rebuild) + `BUILD` (each deploy starts fresh) + `cache_gen` from KV.
- `cache_gen` is bumped on every successful POST to `/admin/*`, `/manage/*`, `/webhooks/*` and on `/admin/seo/reset`, sync, urlsync, insertone, migrate — so admin/owner edits show immediately.
- Never cached: `/admin`, `/debug`, `/manage`, `/account`, login/signup/verify/code/auth/forgot/reset/logout, `/claim`, `/add`, `/api`, `/webhooks`, `sw.js`, non-GET, any request carrying a `gl_sess` or `gl_adm` cookie (those responses now say `private, no-cache`), non-200s and anything with Set-Cookie.
- `x-gl-cache: HIT | MISS | BYPASS` response header.
- `?refresh` (clears in-memory caches) now only works for a logged-in admin — it used to let anyone force uncached D1 queries.
- Version now lives in one constant, `const BUILD`; /debug prints it; precheck checks it.

Tested locally (wrangler dev): MISS→HIT, utm/junk params share the key, logged-in and admin BYPASS, 404 not stored, admin save clears the cache.
