# v16.24-shared (6 Oct 2026)

Weekly map pins, so new listings show on maps without anyone running anything by hand.

- **`geocodeBatch(DB, n)`** looks up lat/lng for listings that have none. It uses the free US Census batch geocoder: one request per batch, no API key, no cost.
  - Writes only to the rows it tries.
  - Addresses it can't match get `geo_tried_at` and are retried after 90 days, so the same misses aren't re-sent every week.
- **Cron:** runs once a week (meta key `cron_geo_at`), up to 1,500 listings per city. Normally only the week's new listings, so it's cheap on Cloudflare limits. No new cron trigger; it rides the existing 5-minute cron.
- **`/admin/geocode?n=`** (admin only) runs a batch now, up to 2,500.
- **Migration:** new column `businesses.geo_tried_at`.
- **Tampa data (no code):**
  - Map pins: 4,245 of 4,714 listings with an address matched (90%).
  - 17 neighbourhood photos from Wikimedia Commons, with credits, via /admin/media/import. The other 8 neighbourhoods had no suitable free photo and keep the drawn picture.
