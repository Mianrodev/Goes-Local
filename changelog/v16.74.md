# v16.74-shared — the profile page greets owners by the Owner Name from GHL

Eric, 23 Oct: the North Carolina demo owner was greeted "Good afternoon, Dev1 Ncdemo Owner", a name made from their email address. On /account, when the session name is only the email-derived name (or empty or a placeholder) and the person owns a listing, the greeting now uses the first word of that listing's **Owner Name** custom field in GHL ("Good afternoon, Dana"). `ownerNameFor()` caches it per email for a day in KV (`oname:<email>`). Names the person set themselves are unchanged. With no Owner Name, nothing changes.

## Status

Deployed to the six state sites. The cities get it on their next deploy.
