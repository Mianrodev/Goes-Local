# v16.58-shared — admin test helper for live QA

`POST /admin/qa-contact` (full admin only) with `action`:

- `create`: name must start with "QA "; tagged `business` + `qa-test`.
- `get`, `set` (custom field by name; a custom-field-only call), `delete`: work only on contacts tagged `qa-test`.
- `delete` also removes the contact's rows from `businesses` and `claims`.

Used to test the GHL "Auto Listing Verification" webhook on the Home Services state sites without touching real businesses.

Also on 20 Oct (data, no code): SEObot (seobotai.com, not a home service) removed from Georgia through Admin → Deletions approve, which untags it in GHL.

Deployed to the six state sites only.
