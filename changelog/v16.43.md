# v16.43-shared — short site name on phones (state sites)

Requested by Eric, 9 Oct. On statewide sites the header and footer name shows in full on wider screens ("Home Services in North Carolina") and with the state code on phones up to 600px wide ("Home Services in NC"). New `BRANDTXT()` is used by `LOGO()`. It only switches on when `CITY_AREA_WORD`/`CITY_AREAS_FROM` make the site statewide and `CITY_BRAND` contains the state name. City sites print exactly the same HTML as before.
