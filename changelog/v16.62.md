# v16.62-shared — sub-category pages win over look-alike listings

Eric (20 Oct): "Yes, fix the General Contractor page too."

## Problem
A listing whose name is just a sub-category ("General Contractor", "Car Wash", "Dentist") got the slug
`/{cat}/general-contractor`, which is also the sub-category page's address. The router shows a listing
first, so the whole sub-category page was hidden behind one business.

## Fix
- `uniqueSlug` never hands out a slug equal to a sub-category in the same category (`subSlugsOf`);
  such a listing gets `-2` (e.g. `general-contractor-2`). Covers the GHL sync, webhooks and imports.
- `migrate()` moves existing listings off those addresses (idempotent). No redirect is recorded: the old
  address now is the sub-category page, which is what people expect there.
