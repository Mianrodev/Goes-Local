# v16.51-shared — safer team access, second locations stay separate (full QA round, 14 Oct)

Found in Eric's full QA round on 14 Oct: the live click-through on Orlando, a smoke test of all three cities, and an independent code review of v16.49–v16.50.

## Live checks on v16.50 (Orlando)

  - "Add another location" fills in the email, including emails that contain the letter "s".

- **Smoke test (Orlando, Miami, Tampa):**
  - Pages checked: home, categories, search, best-of, claim, add, login, about, pricing, blog, robots, sitemap and llms.txt, plus 12 random listing and category pages per city.
  - All return 200 with no template errors. The word "undefined" on one Miami blog post is part of the article's own sentence.

## Fixed

1. **Team access was too wide (security, from the code review).**
   - v16.49 let anyone signed in at the same company email domain as a listing's owner manage that listing. Two State Farm agents (`@statefarm.com`) or two KW realtors (`@kw.com`) could edit or delete each other's listings.
   - Colleagues now get access only when the listing's website is exactly that domain's home page (`OWNSITE`):
     - `sktsalon.com` works for sktsalon.com addresses.
     - Agent sub-pages (`statefarm.com/agent/...`) and agent sub-sites (`john.kw.com`) don't count.
   - Public mail providers, `.edu`, `.gov` and `.mil` never count.
   - The dispute rule uses the same test, so a corporate colleague claiming another agent's listing triggers the 72h notice to the owner.
   - **Effect on Mr Jeff:** their website is jeffcleaners.com but their emails are @laundryus.app. Sergio no longer sees the Coral Way listing automatically. Sales should sign in with connect@laundryus.app, or we add a proper "invite a team member" feature.
2. **A second location could overwrite the first.**
   - If an owner's first location was still waiting (not verified yet), sending a second location within 24h with the same email replaced the first one.
   - A repeat now also needs the same business name.
3. **Area and zip were missing on listings created at go-live (v16.50 path).**
   - The zip is now kept with the request and sent to GHL when the contact is created, so the area can be worked out.
   - The copied description is cut to 600 characters, the same limit as the edit page.
