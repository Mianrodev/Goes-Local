# v16.02-shared (29 Sep 2026)

Better default images, step 1 of Eric's combined plan: real photos where we have them, designed artwork everywhere else.

- **Designed artwork instead of one repeated stand-in photo.** `/art/{hood|cat|type}/{slug}.svg` draws a unique gradient, icon and skyline chosen from the name (`ARTSVG`).
  - Neighbourhoods with no photo (`HOODIMG`) and categories with no photo (`CATIMG`) now use it. Before, they all showed the same Miami stand-in (`DEFAULT_CAT_IMG`).
  - Best-of cards use a business-type photo when one is set, and the artwork otherwise. The list page header uses the type photo, then the category photo.
- **Business-type photos.** Each type can have its own photo (content_images key `type-{slug}`), used on Best-of pages and for claimed businesses without their own picture (`TYPEIMG`). Admin → Category images has a new "Business type photos" section to set or replace them.
- **Photo credits.** `content_images` gains `credit` and `credit_url`. The new `/photo-credits` page (linked in the footer) lists every free-licence photo with its author and licence. Uploading your own photo in admin clears the old credit.
- **Admin import tool** (`POST /admin/media/import`, admin only): copies a free-licence photo from a web address into the site's own image library and assigns it to a neighbourhood, category or business-type slot, with alt text and credit.
